## *Devlog*
### *Scaled the dimensions:* 3h 24m | Oct 24, 2026
I am working without the blueprints of the building, and so to have an accurate miniature model, I had to measure and record every length of the building alone using only a regular tape measure. I had approximate dimensions I was pleased with and scaled it by *0.0225.

### *Interior and Exterior Designs:*  5h 41m | Oct 25, 2026
I added all the spaces where the doors and windows go, still using the same scale.
I also completed the front exterior designs of the building, which are the arches in front of the building.
This actually took a lot of time because once again, I'm still working without the exact measurements of the building. It was really had for me to get the dimensions for the curves, but with some few Math tricks, I was able to get it done :)
But there are some errors I now have to correct. I can't finish this today, I would have to continue next week.
